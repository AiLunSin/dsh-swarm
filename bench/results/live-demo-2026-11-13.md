## Incident found by this test

Auto-dispatch initially failed with `Cannot read properties of undefined (reading 'id')`.

Root cause: DSH 0.2.2-rc.3 changed `startActivation` to take a flat `SubagentActivationSpec`. The plugin still nested the task fields under `request`, so `spec.parent` was `undefined` inside the subagent manager. The published 0.1.0 package contains this bug.

Fix: `src/runner.js` now passes `provider`, `label`, `parent`, `cwd`, `prompt`, `outputSchema`, `maxDepth`, `signal`, and `delivery` at the top level. `test/runner.test.js` asserts the flat shape and parent binding.
